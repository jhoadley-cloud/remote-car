# Parts Research

This folder tracks all hardware needed for the Remote Car project.

The goal is to separate **requirements** from **purchasing decisions**. The project architecture defines what each component must do, while brand, exact model, quantity, source, and budget can be researched independently.

## Files

- `PARTS_LIST.md` — master bill of materials and research checklist

## Suggested research fields

For each item, record:

- exact model
- manufacturer / brand
- quantity
- unit price
- total price
- vendor
- link
- electrical ratings
- dimensions / weight
- waterproof rating
- compatibility notes
- whether it is already owned
- selected / rejected / researching
- reason for final choice

## Selection priorities

For V1, prioritize:

1. compatibility
2. safety
3. reliability
4. waterproofing
5. ease of integration
6. replacement-part availability
7. cost
8. performance upgrades

Do not purchase high-current electronics until connector types, voltage, current limits, and expected drivetrain load are checked against the rest of the system.
