# Safety

- Never bench-test throttle with drive wheels contacting the ground unless the chassis is securely restrained.
- Use a physical battery disconnect that can be reached quickly.
- Do not depend on laptop software as the only emergency stop.
- Maintain an RC path for human intervention during autonomous testing.
- Test failsafes deliberately before testing autonomy.
- Start autonomous runs at walking speed.
- Use geofencing.
- Avoid public roads, sidewalks, crowds, pets, parked vehicles, and steep drop-offs.
- Treat LiPo damage, swelling, overheating, or puncture as a stop-work condition.
